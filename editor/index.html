Tips

  • Publishing writes a new .html file into the site folder — no more hand-editing old files. Existing article1–15.html can be loaded, edited and republished from the dropdown above.
  • Images can't be uploaded by the browser — save your image into the images/ folder yourself, then type its path (e.g. images/my-chart.png).
  • The editor key is printed in the terminal when you run npm run dev. Without it, nobody can publish — on the live static site this page can't save anything at all.
  • After publishing a new article, add a link to it on the homepage (index.html) or a section page so readers can find it.
  • Use the preview's reading-time and layout to sanity-check before publishing.
